Forge is an editor in a classic keyboard-driven tradition: a small core of buffers,
windows and keymaps, configured with Rhai and extended by WebAssembly plugins,
with SDKs for Rust, JavaScript/TypeScript, Python, C and Lua.
Everything you can do at the keyboard is a named *command*, so commands can
be bound to keys, run by name, documented, and remapped without touching the
code that implements them.

This manual is the long-form documentation. It explains concepts and shows
complete workflows; the built-in help answers narrower questions, and every
command also carries its own documentation page.
